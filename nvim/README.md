# AstroNvim Config

This is an [AstroNvim](https://github.com/AstroNvim/AstroNvim) user configuration,
managed as part of this dotfiles repository.

Custom plugins and overrides live in `lua/plugins/`. See `lua/community.lua` for
enabling [AstroCommunity](https://github.com/AstroNvim/astrocommunity) plugin packs.
